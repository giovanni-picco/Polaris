# MeTube

Web UI for yt-dlp: download videos and audio from YouTube and other sites, then save them from the browser.

| | |
| --- | --- |
| **Namespace** | `metube` |
| **Image** | `ghcr.io/alexta69/metube` |
| **URL** | `https://metube.${CLUSTER_DOMAIN}` |
| **Auth** | none (LAN/tailnet only) |
| **State** | downloads in an `emptyDir`, lost on restart by design |
