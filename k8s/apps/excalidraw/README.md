# Excalidraw

Whiteboard for sketches and diagrams. Drawings live in the browser (or are exported); the server only serves the app.

| | |
| --- | --- |
| **Namespace** | `excalidraw` |
| **Image** | `excalidraw/excalidraw`, pinned by digest (upstream only publishes `latest`; Renovate updates the digest) |
| **URL** | `https://excalidraw.${CLUSTER_DOMAIN}` |
| **Auth** | none (LAN/tailnet only) |
| **State** | none |
