# BentoPDF

Browser-based PDF toolkit (merge, split, compress, convert). Everything runs client-side, the server only serves static files.

| | |
| --- | --- |
| **Namespace** | `bentopdf` |
| **Image** | `ghcr.io/alam00000/bentopdf-simple` |
| **URL** | `https://pdf.${CLUSTER_DOMAIN}` |
| **Auth** | none (LAN/tailnet only) |
| **State** | none |
